# SummarizeAI

**SummarizeAI** is a high-performance, AI-powered NLP summarization engine designed to transform long-form content, such as research papers, legal documents, and news articles—into crisp, actionable insights. Built with a focus on privacy and efficiency, it processes text locally to ensure no data leaves your browser.

## ✨ Key Features

* **Dual NLP Algorithms:** Choose between **Extractive Summarization** (using TF-IDF scoring to identify key sentences) and **Abstractive Summarization** (AI-driven rephrasing for a cohesive narrative).
* **Domain Awareness:** Tailored processing for six specific domains: **General, Academic, News, Technical, Legal, and Medical**.
* **Customizable Output:** Adjust the target length from "Tiny" to "Detailed" using an intuitive slider.
* **Compression Analytics:** Get precise metrics on word reduction, reading time saved, and compression ratios.
* **Persistent Summary History:** Automatically save, filter, and favorite your past results for instant retrieval.
* **Key Points Extraction:** Automatically identifies the five most informative sentences as digestible bullet points.

## 🛠️ Tech Stack

* **Frontend:** React 18, TypeScript
* **Routing:** React Router
* **Styling:** Tailwind CSS with custom dark mode support
* **State Management:** React Context API (Auth and Theme)
* **UI Components:** Sonner (Notifications), Lucide React (Icons)
